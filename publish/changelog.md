# 1.0.0 — first release

Same text for both files (NeoForge 1.21.1 and Forge 1.20.1):

```
First release of the unofficial NeoForge/Forge port of Better Mount HUD by Lortseam.

- Hunger stays visible while riding; the mount's hearts move above it.
- Experience bar and level stay visible on jumping mounts; the jump bar shows while you hold jump.
- Air bubbles sit above the mount's hearts.
- Jump bar stays visible while the mount's jump is on cooldown (camel dash).
- Every change can be turned off in the config.
- Client-side only, no dependencies.
- Translations: en, ru, uk, de, fr, es, pt_br, pl, zh_cn, ja, ko.
```
